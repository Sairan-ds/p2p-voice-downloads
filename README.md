Здесь размещены готовые установщики, документация и страница GitHub Pages.
Исходники приложения и сервера хранятся в отдельном приватном репозитории.
Автоматические архивы Source code на странице релиза содержат только эту
страницу и документацию — исходников приложения в них нет.

Для разговора достаточно приглашения в существующий хаб. Личный VPS каждому
участнику не нужен. Сервер хабов хранит комнаты и присутствие; голос идёт
между участниками по зашифрованным соединениям. Учётных записей и ролей пока нет.

Windows-установщик пока без цифровой подписи. Mac-сборка тестовая, без нотариализации Apple. Intel Mac пока не выпущен.

Короткие приглашения `p2pvoice://join/…` доступны с версии 0.1.6. Получить ссылку можно в меню хаба через «Скопировать приглашение» или командой `room-server hub link ИМЯ`. Старые длинные приглашения тоже принимаются.

С версии 0.1.10 клиент сам проверяет новые версии. В настройках: «Загрузить обновление» → «Установить и перезапустить». Старую версию без механизма обновления нужно заменить новым клиентом один раз; дальше скачивать архивы вручную не нужно. Во время звонка установка не запускается.
